# PRODIGY_WD_03

This is a simple Tic Tac Toe game created using HTML, CSS, and JavaScript. The game consists of a 3x3 grid where two players, 'X' and 'O', take turns making moves. The game detects a winner or a draw and displays the result. Players can restart the game at any time by clicking the Restart button.

Key Features:

Interactive Grid: The game board is dynamically generated with 9 cells. Each cell is clickable, allowing players to make their moves.

Turn-based Gameplay: Players alternate turns between 'X' and 'O'. The game automatically switches between players after each move.

Win Detection: The game checks for horizontal, vertical, and diagonal winning combinations after every move.

Draw Detection: If all cells are filled without a winner, the game declares a draw.

Restart Button: A button to restart the game and reset the board.

How it Works:

The board is created using a grid layout (CSS Grid) and is initially empty.

Players make a move by clicking on any empty cell, which is marked with 'X' or 'O'.

After each move, the game checks if there’s a winner or if the board is full (draw).

If a winner is found, the status updates with the winner’s symbol ('X' or 'O').

Players can reset the game at any time with the Restart button.

A Tic Tac Toe game built with HTML, CSS, and JavaScript. Players alternate between 'X' and 'O' on a 3x3 grid. The game detects win conditions (horizontal, vertical, diagonal) and offers a restart button. The game ends when a player wins or the board is full (draw).
